# Bundle File Tool v2.1 Build 128 - Build Record

**Prepared:** 2026-09-04  
**Status:** Source-qualified; delivery prepared; installation acceptance pending  
**Release identity:** `2.1.128`

## Outcome

Build 128 modernizes the BFT web workspace and corrects the long-path failures
visible in the Build 127 browser layout. The source path has a full-width field
and wrapping preview; activity, inspector, and table paths now remain readable
for deep folders and long filenames. Full values are retained as hover text.

The web member of the triad now includes Studio and Midnight skins. The selected
skin is persisted through BFT's per-user state and authenticated loopback API,
so it survives the randomly assigned port used by a later session. The former
letter tile is replaced by a local BFT documents-to-sealed-bundle mark and
favicon. All assets remain dependency-free, CSP-compatible, and local.

Build 128 does not alter core selection, integrity, bundle, extraction, or
progress contracts. CLI and Tk retain the governed PyThermX 0.5.3 Build 16
wheel; web retains NodeThermX 0.3.0 Build 3.
