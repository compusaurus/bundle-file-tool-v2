# Bundle File Tool v2.1 Build 127 - Build Record

**Prepared:** 2026-09-03  
**Status:** Source-qualified; delivery prepared; installation acceptance pending  
**Release identity:** `2.1.127`

## Outcome

Build 127 standardizes the BFT triad on the ThermX progress family while
preserving the renderer-independent `BundleToolService` boundary. CLI and Tk
retain the latest governed PyThermX 0.5.3 Build 16 wheel. The web workspace now
uses the standalone NodeThermX 0.3.0 Build 3 DOM adapter instead of its former
application-specific progress bar.

The browser adapter maps BFT's existing progress DTO and job lifecycle to strict
ThermX Schema 1.1. NodeThermX owns determinate and indeterminate rendering,
accessible status, cancellation intent, details, and terminal outcomes. BFT
continues to own all selection, integrity, extraction, job, and cancellation
policy.

The integration exposed and corrected a producer-side completion inconsistency:
plan and replan completion had reported included paths as `current` against all
decisions as `total`. Those operations now close at all decisions processed and
retain the included-path result in their message. The browser therefore reaches
100 percent from coherent source data rather than a display-only override.
